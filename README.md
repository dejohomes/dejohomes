# Dejohomes website

A mobile-first website for Dejohomes with a Next.js App Router frontend and an embedded Sanity Studio at `/studio`. The site includes current Abuja property offers, listing filters and detail pages, a Sanity content model, enquiry capture, SEO basics and an on-demand refresh endpoint.

## Run locally

1. Install Node.js 20 or later.
2. Copy `.env.example` to `.env.local` and set up a Sanity project (instructions below).
3. Run `npm install`, then `npm run dev`.
4. Open `http://localhost:3000` for the website and `http://localhost:3000/studio` for the editor.

Without Sanity credentials, the website uses the 10 property options transcribed from the supplied flyers in `src/lib/properties.ts`. Their locations, sizes, current prices and previous prices are included. All ten supplied renders are matched by estate and size: Vista Grand Court (200, 300 and 450 sqm), The Dejo Peninsula (150, 250 and 350 sqm), and Downtown Golf Resort (250, 350, 450 and 550 sqm). Contact details remain starter values.

## Sanity setup

1. Create a Sanity project and production dataset at [sanity.io/manage](https://www.sanity.io/manage).
2. Set `NEXT_PUBLIC_SANITY_PROJECT_ID` and `NEXT_PUBLIC_SANITY_DATASET` in `.env.local` and in the hosting environment. Restart the development server after changing them.
3. Visit `/studio`, sign in with a Sanity account, and create the first Site settings document. Add listings under **Property listings**. The listing form uses plain-language labels and fixed dropdown choices; photos can be reordered by dragging.
4. Give team members access from Sanity project management. Assign the least-privileged role suitable for their work (Viewer, Editor or Administrator, depending on the account's available roles). Sanity controls Studio authentication; the app does not store passwords.
5. Add a Sanity webhook for published create/update/delete events. Use `POST https://YOUR_DOMAIN/api/revalidate?secret=YOUR_SANITY_REVALIDATE_SECRET`, send the document body as JSON, and set a generous webhook timeout. Set the same long random secret in Vercel and Sanity. The endpoint refreshes homepage, inventory, listing details and journal pages.

The Studio schemas include listings, blog posts, testimonials, FAQs, team members, gallery items, site settings and enquiries. The Studio includes a lead inbox with search, handled status and CSV export. Enquiries appear there when `SANITY_API_WRITE_TOKEN` is configured. Create a Sanity API token with write access only to the production dataset and keep it server-side.

## Enquiries and spam protection

The contact endpoint validates fields, checks the request origin, applies a five-per-minute IP limit, uses a hidden honeypot field, stores leads in Sanity, and sends an email through Resend when configured. Add `SANITY_API_WRITE_TOKEN`, `RESEND_API_KEY`, `ENQUIRY_TO_EMAIL` and a verified `ENQUIRY_FROM_EMAIL` to the environment. Set `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN` for a shared rate limit across serverless instances; the in-memory limiter is only a development fallback. Do not enable production enquiries until the storage, email and shared rate-limit credentials are present.

## Deploy

1. Put the source repository in a GitHub organization or account owned by Dejohomes.
2. Import it into Vercel, add the environment variables above and set `NEXT_PUBLIC_SITE_URL` to the final HTTPS domain.
3. Connect the Dejohomes domain in Vercel and wait for its SSL certificate before sharing the site.
4. Configure the Sanity webhook with the live domain and revalidation secret.
5. Replace the `wa.me` phone values and all sample contact details/content. Add real project images and listings and confirm title descriptions with the business team.
6. Submit a test enquiry and verify that it appears in Studio and arrives at the configured team inbox.

## Project notes

- Sanity image uploads use the Sanity asset pipeline. Ten supplied property renders are stored in `public/properties/`. The Dejohomes logo is served as an optimized transparent WebP in the header, footer and social share metadata.
- The homepage hero uses the Downtown Golf Resort 450 sqm prototype render.
- Sitemap and robots files are generated by Next.js. Page metadata and Open Graph defaults are in `src/app/layout.tsx`.
- Maps currently link to a Google Maps search for each estate. GA4 and Meta Pixel IDs were not supplied and are not enabled. The consent notice stores a local choice but does not yet gate analytics tags.
- The About, legal, and process page copy is starter copy. Legal pages need review by Dejohomes counsel. No company registration details, real phone numbers, customer quotes, real estate photos or verified title claims were supplied in the brief.
- Lighthouse targets and cross-browser/device checks must be confirmed against the final deployed assets and real hosting configuration.
